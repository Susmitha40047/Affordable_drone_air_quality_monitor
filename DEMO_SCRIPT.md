# Demo Script

## Short Presentation Script

Good morning everyone. Our project title is **Affordable Drone Air Quality Monitoring System**. We are Team Number 5. The team members are G. S. Susmitha, S. Vaishnavi, P. Shruthi, and L. Archana.

The main aim of our project is to monitor air quality at different locations using the concept of a drone-based system. Traditional air quality monitoring stations are expensive and fixed in one place. Our idea is to use a mobile drone platform that can collect pollution data from multiple areas.

Due to time constraints, we implemented the full project as a software prototype. In this prototype, we simulate drone movement, GPS tracking, and air quality data such as PM2.5, PM10, CO2, temperature, and humidity.

The backend is developed using Flask, and the frontend dashboard is built using HTML, CSS, and JavaScript. The dashboard displays the drone route on a map, live sensor values, pollution charts, and alert messages for higher pollution areas. All generated mission data is also saved in CSV format.

This prototype demonstrates the complete workflow of a real drone-based air quality monitoring system and can be extended in future by connecting it with actual sensors and drone hardware.

Thank you.

## Demo Flow While Showing the App

1. Open the dashboard home page.
2. Explain that this is the live monitoring interface.
3. Click **Start Mission**.
4. Show that the drone starts moving on the route map.
5. Point out the live PM2.5, PM10, CO2, temperature, and humidity values.
6. Show the trend charts updating automatically.
7. Show the alert section and explain that it detects pollution hotspots.
8. Mention that all readings are stored in the CSV mission log.
9. Explain that the same dashboard can later connect to real sensors and drone hardware.
