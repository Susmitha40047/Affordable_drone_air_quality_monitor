## Slide 2: Introduction

- Air pollution monitoring is important for public health and environment
- Traditional monitoring stations are costly and fixed in one place
- A drone-based system can monitor multiple areas dynamically
- This project demonstrates the concept through software simulation

## Slide 3: Problem Statement

- Fixed monitoring stations have limited area coverage
- Real-time monitoring at multiple locations is difficult
- There is a need for a low-cost and portable monitoring solution

## Slide 4: Objective

- To simulate an affordable drone air quality monitoring system
- To track virtual drone movement using GPS coordinates
- To generate air quality readings such as PM2.5, PM10, and CO2
- To display live data through a dashboard
- To store mission data for later analysis

## Slide 5: Proposed Solution

- Software prototype of a drone carrying air quality sensors
- Simulated drone route and sensor data generation
- Flask backend for data processing
- Web dashboard for visualization
- CSV logging for mission records
